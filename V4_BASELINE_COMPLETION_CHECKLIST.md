- [ ] Power Apps custom connector
- [ ] Teams embedding / application packaging
- [ ] Dataverse or hosted PostgreSQL production database
- [ ] Cloud deployment and HTTPS hosting
- [ ] Organizational backup / retention policies

Prototype V4 therefore completes the **approved local application prototype plan**. The remaining unchecked work is production integration and deployment rather than missing local workflow functionality.
